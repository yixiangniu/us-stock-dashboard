# US Stock Tracking & Valuation Dashboard

An interactive web dashboard for tracking U.S. stock prices, historical trends, valuation metrics, and educational model ratings.

## Live Demo

https://berber-stock-dashboard.streamlit.app/

## Features

- Search and track U.S. stock tickers
- View candlestick, OHLC, and line charts
- Show trading volume and moving averages
- Compare multiple stocks on one chart
- Support time ranges including 1D, 5D, YTD, 5Y, and Max / Since IPO
- Display basic fundamentals such as market cap, trailing P/E, forward P/E, PEG ratio, profit margin, revenue growth, and debt-to-equity
- Generate an educational rule-based rating: Buy, Considering, or Sell

## Tech Stack

- Python
- Streamlit
- yfinance
- pandas
- Plotly
- GitHub
- Streamlit Community Cloud

## Data Source

Market data and fundamental metrics are retrieved through `yfinance`, which provides access to Yahoo Finance data.

Data may be delayed, incomplete, or calculated differently from official company filings.

## Disclaimer

This project is for educational and portfolio purposes only.  
The Buy / Considering / Sell rating is generated by a custom rule-based model and should not be treated as financial advice.
